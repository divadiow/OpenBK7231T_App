# Native TXW81x firmware packer (research implementation)

This directory contains a standard-library-only Python replacement for the TXW81x post-build operations currently performed by Taixin's Windows tools:

- `BinScript.exe` for Intel HEX remapping and parameter extraction;
- `makecode.exe` for the flashable SPI application image (`APP.bin`);
- `xz.exe` plus `compress.exe` for the compressed OTA image (`APP_compress.bin`).

It deliberately is **not connected to OpenBeken's production Makefile or release workflow**. The generated images still require real TXW81x flash and OTA testing before production integration.

## Files

- `txw81x_pack.py` — pack, inspect and validate APP/OTA images.
- `tests/test_txw81x_pack.py` — synthetic tests plus opt-in known-good Taixin integration tests.
- `tests/reference_manifest.json` — hashes and parsed values for the public upstream Actions reference files.
- `ATTRIBUTION.md` — retained MIT attribution for the RNode-derived portions.

No Taixin executable, SDK source, firmware loader or reference image is included.

## Commands

### Build `APP.bin` from the existing Intel HEX

```bash
python3 tools/txw81x_pack/txw81x_pack.py pack-app \
  --input sdk/OpenTXW81X/project/project.hex \
  --parameter-cfg sdk/OpenTXW81X/project/parameter.bincfg \
  --makecode-ini sdk/OpenTXW81X/project/makecode.ini \
  --sdk-version 02050307 \
  --svn-version 8EB5 \
  --app-version 0 \
  --date 2026-07-12 \
  --output sdk/OpenTXW81X/project/APP.bin
```

The version/date values above reproduce the recorded reference build. A real build must supply the values generated by that checkout. `--template-app` can copy those fields from an existing image during comparative testing, but production packaging should use explicit build metadata.

The packer accepts a raw binary instead of Intel HEX as well:

```bash
csky-elfabiv2-objcopy -O binary project.elf txw81x_fpv.bin
python3 tools/txw81x_pack/txw81x_pack.py pack-app \
  --input txw81x_fpv.bin \
  --parameter-cfg parameter.bincfg \
  --makecode-ini makecode.ini \
  --sdk-version 02050307 --svn-version 8EB5 --app-version 0 \
  --date 2026-07-12 --output APP.bin
```

### Build `APP_compress.bin`

```bash
python3 tools/txw81x_pack/txw81x_pack.py pack-ota \
  --app APP.bin \
  --loader sdk/OpenTXW81X/sdk/chip/txw81x/loader_compress.bin \
  --output APP_compress.bin
```

The loader is consumed from the existing OpenTXW81X checkout. It is not copied into this project.

### Inspect either format

```bash
python3 tools/txw81x_pack/txw81x_pack.py inspect APP.bin
python3 tools/txw81x_pack/txw81x_pack.py inspect APP_compress.bin
```

Output is JSON and includes every parsed header, important addresses, lengths, version fields and checksum results.

## Tests

Always-available tests:

```bash
python3 -m unittest discover -s tools/txw81x_pack/tests -v
```

Known-good integration tests require the two public OpenBeken Actions outputs and the existing submodule loader:

```bash
TXW81X_REFERENCE_DIR=/path/to/reference/files \
TXW81X_LOADER=sdk/OpenTXW81X/sdk/chip/txw81x/loader_compress.bin \
python3 -m unittest discover -s tools/txw81x_pack/tests -v
```

The integration suite verifies the manifest hashes, parsed fields, all CRCs, deterministic output, byte-identical `APP.bin`, and byte-identical `APP_compress.bin`.

## Current validation status

Validated in software:

- known-good APP reference SHA-256: `461b527fd88b3bae15e684d27775c2ee0409f4d09c6da0a638fd2f433568b562`;
- rebuilt APP is byte-identical;
- known-good OTA reference SHA-256: `dca07019a9f1e5f18ae9b63c175c8067ec70de9af08527abdd697b27eca15c04`;
- rebuilt OTA is byte-identical;
- XZ payload is byte-identical using Python `lzma`, preset 0, 32 KiB dictionary;
- no Wine, Windows executable or WSL is used by the packer or tests.

Not validated:

- booting a Python-generated APP image on physical TXW81x hardware;
- applying a Python-generated compressed OTA on physical hardware;
- all possible `makecode.ini` options, especially AES/encryption and non-SPI image types;
- automatic derivation of SDK/SVN/application version metadata from every supported build configuration.
